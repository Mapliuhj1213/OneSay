# 更新日志

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号见 `app/AndroidManifest.xml`。
2.5.0 之前的条目由 `git log` 中「版本号改为 …」提交整理而来，只列主题；细节见对应提交与 `docs/`。

## [未发布] — 首个开源版本

### 新增
- 设备能力探测层与功能注册表（`com.onesay.assistant.v2.platform`）：启动时探测 root、Shizuku、无障碍、厂商 / 机型、Android 版本、按键、所需权限；「关于 › 设备能力与功能」按注册表列出每个功能，不可用的置灰并写明原因。只读展示与已有开关，不改任何默认值。
- 设备相关接口：唤醒入口（`WakeEntry`）、root 操作（`RootOps`）、厂商专属服务（`VendorServices`），附无 root 替代方案说明。
- 开源工程文件：LICENSE（占位）、THIRD_PARTY_NOTICES.md、CONTRIBUTING.md、CODE_OF_CONDUCT.md、SECURITY.md、issue / PR 模板、.editorconfig、GitHub Actions（JVM 测试 + 编译检查 + 秘密扫描）。
- `GEN_DEBUG_KEYSTORE=1`：没有任何私有文件也能编 debug 包。

### 变更
- 云端朗读的默认音色 / 业务空间 ID 改为构建时注入（`LocalDefaults`，本机值放未跟踪的 `local-config/`）；本机构建行为不变。
- `run_unit_tests.sh` 支持把编译输出放到别处、只编译 / 只运行。
- 大模型服务地址（DeepSeek / 百炼兼容模式 Base URL）可在「API 密钥」页配置，只收 https，Key 只发往所配主机（`net/LlmEndpoints`）。
- 跨 App 通道（Plan 数据接口、BRIEF_STATE 广播、快速读屏助手、exec 守护）不再内置任何证书指纹，只认同一证书签名的对方或用户自行配置的证书。
- 主人守则换成简短的通用示例文本。

### 安全与隐私
- 测试样例中的真实邮箱 / QQ 号换成合成值；文档中的账号 ID 打码；探针脚本不再打印 key 片段；`.gitignore` 补齐日志、证据目录、签名配置。
