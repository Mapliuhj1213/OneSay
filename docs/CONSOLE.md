# 控制台条目清单（手机设置区 ↔ 电脑端设置页）

> 2026-11-12 起（分支 console-align）。手机（个人版 / 开源版）与电脑端各仓各放一份，内容相同。
> 改任何一端的设置分组、条目名字、危险项或状态颜色，先改这份清单，再改两端代码；三处测试会对照它
> （手机 `ConsoleAlignTest`，电脑 `ConsoleAlignTest`）。

## 三、写法

- **卡片**：白（深色模式为深灰）底大圆角卡片，圆角 22；卡片内一行一项，行间细分隔线。
- **标题层级**：页标题（手机顶栏 22 / 电脑 34 px）→ 分组标题（13，中粗，次级字色，左边 4×14 的主色短条，后面可跟一句灰色说明）→ 行标题（手机 16 / 电脑 15，常规）→ 行说明（手机 13 / 电脑 12.5，次级字色）。
- **开关与说明**：开关一律在行的右边；行标题写「做什么」（名词或动宾短语），说明写「开了会怎样 / 用在哪」，一句话，不写「是否」「启用」。
- **危险项**：按钮文字是下表的动词时，一律红字（手机红字红底胶囊，电脑红字）；点了先弹确认框。
  危险动词：清空 · 清除 · 删除 · 撤销 · 解除 · 解除配对 · 卸载 · 关机 · 睡眠 · 换一把钥匙 · 忘掉 · 重置 · 停止
- **确认框**：标题「动作 + 对象？」（如「撤销「X」？」「换一把钥匙？」）+ 一句后果 + 动词按钮（危险动词写红）+「取消」。
- **主色**：手机保持苔绿（与灵动岛一致，深色默认），电脑保持蓝；两端共享的是结构、字号比例、危险红和下面的状态色。

## 四、状态徽标（与控屏颜色一致）

| 状态 | 颜色 | 什么时候 |
|---|---|---|
| 操作中 | 蓝紫 #7C7CFF | 助手正在替你点按；电脑上下载任务进行中 |
| 等确认 | 琥珀 #FFB020 | 弹确认卡等你点；电脑右下角确认框 |
| 你接手 | 绿 #34C759 | 你点了接管 / 按了返回或主页键 |
| 已停止 | 红 #FF453A | 点了停止；电脑上下载被取消 |

手机来源：`exec/ControlColor`（屏幕边框 / 灵动岛描边）、`ui/console/ConsoleStyle`；电脑：index.html 的 `--ctl-run / --ctl-wait / --ctl-user / --ctl-stop` 与 `.tag.run / .wait / .user / .stop`。
