# OneSay 设计语言 v1（手机 · 灵动岛 · 悬浮面板 · 电脑端共用）

一句话：**安静的底色，颜色只表达意思。** 页面是中性灰白 / 炭黑，主色苔绿只用在「开着 / 主要动作」，红黄绿灰只用在「状态」，蓝紫只用在「助手在控屏」。

### 1.3 状态色（四种，只用于状态点 / 状态字 / 提醒条）
| 状态 | 意思 | 深色 前景 / 底 | 浅色 前景 / 底 |
|---|---|---|---|
| ok 绿 | 好了 / 已开启 | #5BC27A / #1C2E22 | #1F7A44 / #E1F2E7 |
| warn 黄 | 待确认 / 没测到 / 部分可用 | #F2B33D / #3A2F1C | #845A0B / #F8EDD3 |
| bad 红 | 没好，影响使用 | #F0575C / #3A1D1E | #C9363B / #F8E1E1 |
| off 灰 | 可选项没开（不是错误） | #7E7C78 / #26262A | #8A8781 / #EEECE7 |

规则：必须项只用 红 / 黄 / 绿；可选项只用 灰 / 绿（可选项永远不变红）。状态永远「点 + 字」一起出现，不只靠颜色。

### 1.4 控屏色（只用于替你操作：屏幕边框、岛描边、电脑确认框）
操作中 #7C7CFF · 等确认 #FFB020 · 你接手 #34C759 · 已停止 #FF453A（与 `exec/ControlColor`、电脑 `--ctl-*` 一致，不变）。

### 1.5 灵动岛 / 悬浮面板
岛：两种模式都纯黑 #000000，文字 #F2F1EE / #A9A7A2；状态点用 1.3 的状态色；聆听波形用 accent。
悬浮面板：跟随控制台主题（深 surface / 浅 surface），**不再写死 iOS 系统色**：
聆听中 = accent，正在识别 / 正在解析 / 正在处理 = text2 + 进度条 accent，想问你一下 = warn，没听清 = warn，已拦截 / 异常 = bad，已停止 = off。
（现状 7 个硬编码色 #30D158 #FF9F0A #0A84FF #5E5CE6 #64D2FF #8E8E93 #FF453A 全部换成 token。）

- 圆角：Hero 24 · 卡片 20 · 提醒条 16 · 输入框 12 · 芯片 / 按钮 / 岛 全圆。
- 电脑端：内容最宽 760，侧栏 232，卡片圆角 20，行内边距 20。

## 5. 文案
- 短、口语、说结果：「没开：说话后面板显示不出来」而不是「SYSTEM_ALERT_WINDOW 未授予」。
- 行标题 = 做什么（名词 / 动宾）；说明 = 开了会怎样，一句话，不写「是否」「启用」。
- 主页面（首页、权限配置、基础设置、插件列表）不出现：Root、Shizuku（只在执行通道说明里出现一次）、IMAP、MCP、OpenAI 兼容、kill-switch、内部代号（S1/S2/S3、#9、C3、v3）、厂商模型名写死在标题里（「DeepSeek」→「主模型」）。
- 状态词固定：好了类「已开启 / 已授权 / 已配置」；没好类「没开 / 没授权 / 没填」；不确定「待确认（没测到）」。
- 动作词固定：去开启 · 去授权 · 去填写 · 打开 · 重读 · 加入。
- 品牌：用户可见文字不出现手机厂商或其他语音助手的品牌名。按键一律叫「按键」「唤醒键」「侧键」。

## 6. 落到代码（实现对照）
- 手机：`ui/console/ConsoleTheme` 换成 1.1–1.3 的值并新增 ok/warn/bad/off 四组；`ConsoleKit.group` 去掉色条；`switchLinkRow` 关时不可进细项；`ConsoleStatus.Level` → 状态色；`FloatingSheetService` 的硬编码色改走 `ConsoleTheme.current()`。
- 电脑：`index.html :root` 换同一组变量，加 `@media (prefers-color-scheme: dark)` 和手动切换；`--accent` 改苔绿；侧栏 `.ic` 改单色；`.sec i` 色条去掉；`.tag.*` 用状态色。
